ccp_

A different Claude Code account in every folder. Work repo → company account; personal project → personal account; experiments → DeepSeek. The switch happens on its own, just by cd-ing. Una cuenta de Claude Code distinta en cada carpeta. Repo de trabajo → cuenta de empresa; proyecto personal → cuenta personal; experimentos → DeepSeek. El cambio ocurre solo, con hacer cd.

01First time — five commandsPrimera vez — cinco comandos

Run them in order. Step 5 is what tells you it worked.Córrelos en orden. El paso 5 es el que te dice que funcionó.

Why a shell function? The binary runs in a child process and cannot change your terminal's environment. The function can — that is why ccp install puts it in your rc, and why cd alone can flip the profile. ¿Por qué una función de shell? El binario corre en un proceso hijo y no puede cambiar el entorno de tu terminal. La función sí — por eso ccp install la mete en tu rc, y por eso un simple cd puede cambiar el perfil.

03Unattended: rotate profiles on a usage limitDesatendido: rotar de perfil al topar un límite

A live claude cannot change profile — its credentials are read once at startup. ccp session runs it as a child, watches for the limit, hands the session off and relaunches it elsewhere. Six steps, each verifiable before the next. Un claude vivo no puede cambiar de perfil — sus credenciales se leen una sola vez al arrancar. ccp session lo corre como hijo, vigila el límite, presta la sesión y la relanza en otro lado. Seis pasos, cada uno verificable antes del siguiente.

The row you'll hit first. ccp auto init never writes an allow_from entry for default. In a directory with no path rule the primary is default, so the whole chain shows up denied and --dry-run prints chain: (empty). Set a rule (ccp path set . <profile>), or open the gate from where you are with ccp auto chain add <profile> — it authorises the loan as well as listing it. El tropiezo que tendrás primero. ccp auto init nunca escribe una entrada allow_from para default. En un directorio sin regla de ruta el primario es default, así que la cadena entera sale denegada y --dry-run imprime chain: (empty). Pon una regla (ccp path set . <perfil>), o abre la verja desde donde estás con ccp auto chain add <perfil> — además de listarlo, autoriza el préstamo.
